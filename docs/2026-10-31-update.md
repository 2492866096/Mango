# 2026-10-31 功能与修复记录

源码版本：4.9，内部构建号：7009。本轮不生成 APK。

## 使用入口

| 功能 | 入口与行为 |
| --- | --- |
| 隐藏代理图标 | 扩展中心 → 外观；默认关闭，开启后隐藏对话列表的代理图标，代理连接继续正常工作。 |
| 禁止下拉展开搜索框 | 扩展中心 → 外观；默认关闭，开启后仍可点击搜索按钮。 |
| 折叠消息功能菜单 | 扩展中心 → 聊天工具；默认关闭。超过 6 项的菜单显示约一半操作，其余放入“更多功能”，支持返回和滚动。 |
| 同步所有账号的扩展功能开关 | 扩展中心 → 工具；默认关闭。开启时把当前账号的开关应用到所有已登录账号；开启期间各账号后续修改继续同步，新登录账号继承最新快照。只同步功能开关，聊天目标、历史记录、文字和数字参数保持各账号自己的设置。 |
| 账号安全检测 | 扩展中心 → 隐私；读取服务器上的手机号可见范围与两步验证状态，点击进入当前账号的对应设置。失败时支持重新检查。 |
| 底部标签排序 | 长按底部标签后横向拖动，松手保存；长按后不拖动保留原快捷动作。取消拖动恢复原顺序，隐藏后再显示标签保留排序。 |
| 扫码登录相册选择 | 设置 → 设备 → 扫码登录，点击相册图标选图。未授权摄像头时，也可在提示框点击“从相册选择二维码”。 |

## 修复

- 头像与消息错位：向上查找同发送者消息时不再替换头像所属消息，统一位置、动画偏移和相册边界的计算。
- 下载加速：运行中变更档位即时调整请求窗口并补充请求，暂停恢复后的任务也使用最新设置。保持已有分片边界，限制每个文件的并发请求与在途数据量。
- 部分设备复制闪退：替换旧 Android 不支持的字符分类调用，校验失效或越界选区，并保护文本转换和剪贴板写入。写入失败时保留选区，不显示复制成功。
- Hold 认证说明已删除“仅在本机显示”句子。
- 同步下载悬浮窗开关时立即应用到当前前台账号，后台账号的设置不会误关闭当前悬浮窗。
- 手机号隐私跳转前同时加载可见性和通过号码查找两类规则，避免缺少缓存时覆盖原有查找限制；两步验证后续页面保持原账号。
- 相册二维码在后台缩放解码，经过登录令牌校验和原有登录接口；取消、关闭页面及重复回调均有保护。
