## 4.6 新入口速查

- **选词屏蔽**：长按消息 → 选词屏蔽 → 长按原文选词并添加 → 提交。最多 5 个词句，提交才保存并开启关键词过滤。
- **下载／上传加速**：扩展中心顶部常用区，拖动分档滑条，保存后生效。
- **私聊批量发送**：扩展中心 → 自动化 → 私聊批量发送。输入内容 → 完整加载普通／归档会话与屏蔽名单 → 核对人数和内容 → 确认发送；每 3 秒提交一条，静音后台执行。可取消剩余任务；断网等待，进程重建需再次确认继续，退出登录清除任务。仅现存私聊用户，不含自身、机器人、群组、频道、屏蔽及付费用户。
- **加入分组**：聊天／群组／频道右上角三点 → 添加到文件夹，可选已有或新建文件夹。
- **日夜模式**：会话列表右上角三点 → 日间／夜间模式。
- **自动下一条**：扩展中心 → 聊天工具，开启后支持语音、圆形视频和普通视频；全屏视频可衔接已加载的后续视频。

## 使用入口与行为

设置 → 扩展中心 → 聊天工具。

1. **自动播放下一个音频**：默认开启。关闭后音乐、语音、圆形视频消息播完当前项即停止；手动上一项/下一项仍有效。
2. **内置代理**：代理设置里的手动更新会合并正在进行的同步，删除后先恢复上次成功订阅并启用。默认订阅没有缓存时尝试预置节点。远端失败但本地恢复成功时会明确提示；恢复配置不代表节点一定能连接。
3. **我的壁纸**：选择“添加自己的内置壁纸”导入图片，保存到应用私有目录。支持预览、应用、重复内容去重和长按删除。删除壁纸库图片不会删除正在使用的背景副本。
4. **每日定时消息**：每个任务选择群组或机器人，填写消息和本机时间，可编辑、删除、开关自动发送，也可手动“立即发送”。开启自动会提醒：应用必须前台运行、屏幕点亮、对应账号联网；后台、关闭、断网错过的任务不会补发。手动发送计入当天记录，防止当天再自动发送；再次明确手动发送允许重试。界面显示“加入发送队列”，实际送达和签到结果需在聊天里查看。付费消息目标不会自动扣费发送。
5. **在线状态与伪输入**：可设置 1–60 分钟的限时在线/离线上报，结束恢复原隐私设置。输入状态可选文字、录音、选贴纸，并指定会话和持续时间；退出应用、熄屏、到期或开启隐藏输入后停止。Telegram 不允许任意修改服务器记录的最后上线日期，因此没有提供虚假的历史上线时间承诺。其他登录设备、隐私规则和实际活动仍会影响别人看到的状态。
6. **消息标签**：长按消息选择标签（重要、待处理、待回复、收藏），可多标签；多选消息后也可批量修改。消息管理中心支持按标签筛选、修改和清除标签、跳转原消息，并提示原消息不可用的情况。可在扩展中心开启底部“消息管理”入口。标签按账号和登录用户身份隔离，仅存本机，密聊不额外保存明文摘要。
7. **菜单排序**：消息菜单与双击操作中，点击复制/转发/收藏/待处理并选择新位置；只排列这些操作，其他原有菜单项和权限不变。
8. **双击操作**：可选点赞/已有快捷表情、回复、无操作。默认保留已有表情行为，回复沿用原有回复逻辑和权限判断。

## 验证

完整 Android Debug 构建（macOS Android Studio JDK）：

```sh
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew :TMessagesProj_App:assembleAfatDebug --offline --console=plain
```

代理、音频偏好、壁纸存储回归：

```sh
python3 Tools/extension-tests/run_media_proxy_tests.py
```

消息标签/菜单排序与资源回归：

```sh
python3 Tools/tests/run_message_management_tests.py
```

每日时间窗口测试：

```sh
mkdir -p build/daily-schedule-tests
javac -d build/daily-schedule-tests TMessagesProj/src/main/java/org/telegram/messenger/DailyScheduleWindow.java Tools/tests/DailyScheduleWindowTest.java
java -cp build/daily-schedule-tests DailyScheduleWindowTest
```

覆盖当天去重、手动记录、重启/离线不补发、编辑时不误发、跨日、时钟回退、夏令时跳过与重复分钟。自动任务使用本地时区，夏令时重复分钟最多执行一次。

模拟器测试构建与使用参见 `Tools/extension-tests/README.md`。测试在一次性、未登录的模拟器副本运行，覆盖页面渲染、真实 Android 本地偏好/标签存储、24 种菜单排序、账号隔离、壁纸文件生命周期；不会向真实联系人发送测试消息。

真实账号的消息送达、机器人签到结果、其他设备看到的在线/输入状态，以及实机媒体播完切换仍需联网设备验证。这些不能由未登录的模拟器测试代替。
