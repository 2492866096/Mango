# 本地消息分析与纪念堂

新增的三个入口都在「拓展功能」。单人聊天右上角还可直接打开该聊天的互动统计；聊天菜单也可直接保存当前会话到纪念堂。

## 反诈骗提示

默认开启本地关键词提醒。查看收到的消息时，命中词库后显示「检测到关键词“…”存在诈骗风险，请注意小心！」，不隐藏消息。词库支持编辑、清空、恢复默认；每行一词，最多 200 词，每词最多 80 字；英文忽略大小写并兼容全角字母。自己发送的消息与服务消息不提醒。每个账号、会话、消息版本、命中词在本次运行期间只提醒一次；修改词库会清除去重记录。

实际聊天显示接入由 `ChatActivity.scheduleScamHint()` 完成；词库不会上传到服务器。

## 互动频率统计

从本机 `messages_v2` 选择一个人，按开始日和结束日（均包含）查看发出数、收到数、活跃天数、日期范围天数、日均消息数、每活跃日消息数及首次/最后消息日期。日期按设备时区计算，夏令时不会造成天数偏差。

只计本地已保存、`mid > 0` 且 `send_state = 0` 的消息。未发送成功、草稿或未缓存历史不计入。该页不会为补齐统计请求服务器历史；显示数量不等于账号的全部历史。

## 消息纪念堂

可从仍有本地历史的会话创建快照，已停用用户以及已退出、被移除或不可访问的频道/群组优先列出。也可提前保存尚可访问的会话。秘密聊天不在此列表内。

创建时读取所有本地消息，保存消息编号、日期、方向、发送者名称、完整文字与媒体类型，并独立复制已经下载的媒体附件。大附件复制在专用队列执行。先写临时目录，成功后原子重命名发布，失败的快照不会显示。

快照位于应用私有文件目录 `message_memorial/<account>_<owner>/`，按账号槽位与登录用户 ID 隔离。关闭并重新启动应用、删除原会话或移除原附件都不会影响已有快照。未下载的附件不会自动补拉。只读浏览器按每页 100 条分页，点击可看完整文字或打开保存的附件；没有发送、编辑或转发入口。长按纪念堂列表项可删除该快照和本地附件查看副本。

## 验证

- `python3 Tools/tests/run_message_insights_tests.py`：执行生产关键词/日期规则与从生产 Java 中提取的真实 SQL，对实际 `messages_v2` schema 建立 SQLite fixture，覆盖日期边界、夏令时、Unicode匹配、发送状态、不同会话隔离及完整快照查询。
- `Tools/extension-tests/MessageInsightsInstrumentationChecks.java`：在未登录测试模拟器中以临时内存身份测试原生数据库读取、快照生成、复制附件、原会话与附件删除后读回、分页、用户隔离及删除。生产账号配置不写入；数据与内存身份在测试后恢复。
- 同一 Android instrumentation 还覆盖持久撤回消息的空页多条恢复、向前/向后分页、围绕消息加载和去重。
