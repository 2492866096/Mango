# Mango IM 4.0 使用与验证说明

最新源码版本与本轮说明见 [4.2 更新记录](v42-release-notes.md)。以下为此前版本记录。

本轮版本升级为 **4.0**，`APP_VERSION_CODE=7000`，通用 Debug APK 的 `versionCode=70009`，安卓包名改为 **`app.mango.im`**。

改包名后会作为独立应用安装，可与旧包名共存。Android 不会自动继承旧应用的账号登录、本地设置和文件；新包需要重新登录、配置相关功能。Telegram 云端聊天在登录后按账号同步。

## 功能与入口

| 本轮需求 | 入口与行为 |
| --- | --- |
| Root 模拟终端 | 设置 → 设备信息，连续点击“应用版本”5次激活入口；两次点击间隔超过1.5秒、点击其他行或离开页面会重置未完成的连击。终端仅在 `su` 确认 `uid=0` 后执行输入的命令，无 Root 不会降级执行。后台读取输出，可取消，60秒超时，最多显示64KB输出，不保存命令历史。 |
| 在线随机签到 | 拓展功能 → 每日定时消息 → 添加或编辑任务。默认“在线随机签到”，可设置每天允许的起止时段；时段内前台联网后随机等待15–90秒尝试一次。旧任务迁移到随机模式，同时保留“每日固定时间”和手动“立即发送”。当天执行记录和待执行时间保存在本机，重启、修改任务不会清空当天记录。 |
| 强制置顶修复 | 原有强制频道配置继续使用。修正新版会话列表的强制置顶顺序和缺失会话的加载，使目标频道在默认会话列表及默认筛选页可见。 |
| 批量退出频道或群组 | 拓展功能 → 批量退出群组与频道。可按频道、群组或全部筛选，多选或全选当前显示列表，确认后依次退出；展示逐项结果，可停止后续任务或重试失败项。包含归档会话；自己创建的会话需先转让所有权。 |
| 本地保存撤回消息 | 拓展功能 → 本地保存撤回消息，自由开关。开启后保存收到撤回时本机已有的消息，按账号隔离；配合拦截撤回可在重新进入聊天时恢复显示。拓展功能 → 本地撤回消息可查看、清空已保存副本；关闭仅停止新增保存。密聊和限时消息不保存。 |
| 反诈骗提示 | 拓展功能 → 反诈骗关键词提示。可开关，每 2 小时读取远程词库，也可立即更新；展示远程词数、来源与最近更新时间。可按账号添加或清空补充词；查看收到的消息时，命中关键词会显示本地提醒。同一条消息在本次运行中不重复弹出。 |
| 消息跟发 | 拓展功能 → 消息跟发，选择需要自动跟发的会话；也可长按消息手动跟发。以自己的身份跟发新收到的支持内容，自动模式需要前台、亮屏且在线，每个会话最多每3秒一条。限时、受保护及付费内容不跟发。 |
| 重复文件智能清理 | 拓展功能 → 重复文件检测与清理 → 检测重复文件。扫描应用已配置媒体目录及应用专用下载目录，通过大小与 SHA-256 比较；默认每组保留最早副本，智能勾选其余副本，也可手动选择、长按预览。确认后在后台二次校验并删除；至少保留一份，跳过临时文件、符号链接、加密文件、近期写入及正在传输的文件。 |
| 互动频率统计 | 拓展功能 → 互动频率统计，选择聊天对象和日期范围；聊天菜单也可进入。显示收发数量、活跃天数、日均频率和范围内首次/末次聊天。统计本机已有且发送成功的消息，不自动补拉未缓存历史。 |
| 消息墓碑 | 拓展功能 → 消息纪念堂。可为已停用账号、无法访问频道或自行选择的会话保存只读快照，复制本地已有消息与已下载附件；清理原会话或重启后仍可阅读。纪念堂不能发送、编辑或转发；长按条目可删除本地快照。 |
| 内置代理显示修复 | 原有代理列表及手动更新入口。内置节点使用明确标记显示，当前代理选择与实际连接保持一致；删掉后可手动更新恢复。与强制频道列表加载一并修复“生效但不显示”的情况。 |

自动签到只在应用前台、屏幕点亮且当前账号联网时触发。离线期间不会后台发送；随机模式在允许时段内重新上线可重新随机等待，固定时间模式错过不补发。手动发送计入当天自动执行记录，用户再次主动点击仍可重复发送。

## 4.0 反诈词库增量更新（仅源码，未重新打包）

- 词库直链：[反诈.txt](https://1812652903.cdn.123clouddisk.com/1812652903/GY/%E5%8F%8D%E8%AF%88.txt)，按 UTF-8 每行一个关键词读取，自动规范化和去重。以后修改该文件即可分发新词库，无需重新发包。
- 反诈开启且至少一个账号已登录时，每 2 小时自动检查一次；应用内定时器与持久化、联网约束的 Android JobScheduler 配合运行，不依赖打开聊天或收到新消息。系统省电可能推迟后台任务，重新打开应用时检查过期更新。
- 增加“立即更新词库”、词数、最近更新时间和更新状态。首次未下载时使用内置词；网络失败或远程文件异常保留上次有效缓存。过期更新失败后应用运行期间每 5 分钟重试，系统后台重试按调度退避策略执行。
- 远程词库与各账号的自定义补充词分开保存。远程替换不会清空补充词，“清空补充关键词”不会删掉远程词库。只下载公开关键词，不上传聊天内容。
- 本次不再升级版本号，保留 **4.0 / 7000**；只改源码，不生成、覆盖或安装 APK。下列原有安装包与完整构建记录属于本增量修改之前。
- 本次验证：反诈下载、解析、缓存、账号隔离、两小时定时器及系统任务 68 项离线回归通过；原关键词与 SQL 规则 16 项通过。修改的 5 个 Android Java 文件使用 Android 35 和已有工程编译产物做独立编译通过，中英文资源 AAPT2 编译、Manifest XML 与 `git diff --check` 通过。未重新打包或进行新版 APK 实机验证。
