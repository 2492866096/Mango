# Mango 4.2 extension center audit

This source-only audit covers the extension center work. No APK was assembled.

- `ExtensionFeaturesActivity` now presents seven category tabs and a persistent search field.
- `MangoFeatureRegistry` registers 14 new behavior switches with bilingual labels, descriptions, and category ownership.
- Search combines the Mango catalog, 59 child-setting entries, and Telegram's existing `ProfileActivity.SearchAdapter`, so a standard Settings result still opens its native destination.
- `MangoSettings` scopes values to account slot plus signed-in owner, records up to 200 typed changes, and restores missing keys by removing them rather than writing a misleading zero or empty value.
- `MangoLegacySettings` observes behavior preference stores and restores through real setters. Reset uses a two-step dialog, stops automation/presence, and retains login, messages, media, task contents, labels, and proxy credentials.
- Story visibility changes publish story invalidation notifications; quote/spoiler changes publish interface updates.
- `ApplicationLoader` initializes the observer for each active account from the extension ticker.

Verification:

- `python3 Tools/tests/run_mango_settings_tests.py`: 25 assertions passed.
- `python3 Tools/tests/check_mango_center.py`: 14 switches, 59 child entries, 60 bilingual resources, and all navigation destinations passed.
- `aapt2 compile` passed for `values/v42_center.xml` and `values-zh/v42_center.xml`.
- `git diff --check` passed.
