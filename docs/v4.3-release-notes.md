# Mango 4.3

版本号：`4.3`（`7003`）

## 新增

- 可隐藏聊天中的表情回应列表。
- 可隐藏表情回应提醒、未读回应提示和回应通知。
- 发送消息、媒体、语音和贴纸后可自动收起键盘，开关位于扩展功能。
- 贴纸可隐藏消息时间和发送状态，骰子与动态 Emoji 不受影响。
- 诈骗用户名单支持每行一个 ID、用户名或 `@用户名`，默认读取：
  `https://1812652903.cdn.123clouddisk.com/1812652903/GY/%E9%AA%97%E5%AD%90%E6%A0%87%E8%AE%B0.txt`
- 诈骗用户名单和诈骗关键词均支持每两小时自动刷新；名单支持手动刷新、清空和恢复内置直链。
- 扩展功能和主题设置中加入三个内置 Telegram 主题入口。

## 修复

- 修复诈骗用户提醒只在首次打开时生效：去重改为本次聊天访问，重新进入会再次检测。
- 同屏多个名单用户依次提醒，关闭当前提醒后继续检查；消息控件复用不再丢弃其他命中用户。
- 名单下载完成、用户资料更新、聊天恢复或页面动画结束后重新检测。私聊没有来信也检查对方身份，照片和贴纸按实际发言者匹配。
- 提醒实际显示后才记为已提醒，避免页面切换拦截弹窗后永久漏报。
