# 芒果 4.5 频道名单

## 诈骗用户与频道标记

沿用“诈骗用户与频道标记”设置中的 HTTPS 文本直链，每行一条：

```text
7637374698
@username
@channel_name
-1001234567890
channel:1234567890
@channel_name/-1001234567890
```

正数是用户 ID。频道用 `-100` 前缀，或 `channel:原始ID`。用户与频道的数字 ID 分开匹配，避免同号串标；用户名按大小写不敏感的完整用户名匹配，支持启用中的备用用户名。

打开频道会检查频道本身；群聊中可见的频道身份发言也会检查。照片、视频、贴纸不影响身份匹配。每次进入聊天，同一用户或频道最多提醒一次；重新进入可再次提示。弹窗的“打开频道”使用当前账号打开频道资料。

名单仍每两小时更新，保留手动更新、失败保留旧名单、名单更新后重查当前聊天的行为。

## 登录后加入反馈频道

来源固定为：

```text
https://1812652903.cdn.123clouddisk.com/1812652903/GY/MG.txt
```

支持每行公开频道用户名（带或不带 `@`）或 `https://t.me/用户名` / `https://telegram.me/用户名`。忽略空行及 `#` 注释，用户名去重。只加入公开广播频道，群组和用户不会加入。空名单会清空后续加入任务。

每个账号首次登录时重新读取直链；已有账号启动时检查已缓存名单并读取到期的远程名单。存活期间每两小时刷新名单和检查成员状态，已经加入的频道直接跳过。配置和正在执行的任务均按账号槽位及登录用户 ID 隔离，退出登录或槽位换号后旧请求不会继续操作新账号。

HTTP、解析、加入失败后自动重试；加入失败最少等待五分钟，服务器 `FLOOD_WAIT` 会按要求延迟。解析或存储失败保留旧缓存。任务串行执行，超时的旧回调会被忽略。
