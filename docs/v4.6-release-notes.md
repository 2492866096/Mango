# 芒果客户端 4.6

版本：`4.6`，基础版本号：`7006`。本轮更新源码，不生成 APK。

## 10 月 17 日交互与稳定性更新

### 聊天与会话列表

- **选词屏蔽广告**：长按一条带正文或说明文字的消息，选择“选词屏蔽”；在底部面板长按原文选词，点击“添加屏蔽词”，最多选 5 个词句。确认提交后一次性保存并开启已有关键词过滤；取消面板不保存。关键词仍可在扩展中心的广告屏蔽页面管理。
- **置顶不再刷新回落**：拖动即保存本机顺序与数据库，松手或离开页面时同步服务器；无限置顶与普通置顶按完整混合顺序恢复，过期网络响应不会覆盖新的拖动结果。文件夹置顶顺序也会保存。
- **日夜快速切换**：会话列表右上角三点菜单提供日间／夜间切换；修复自定义日间主题的亮暗识别。
- **快捷加入分组**：私聊、群组、频道右上角三点菜单选择“添加到文件夹”，可加入已有文件夹或新建。已有归属显示勾选，此入口不取消已有归属；文件夹容量限制沿用原生流程，按当前账号保存。

### 扩展中心

- 搜索区改为自适应纵向布局，输入框和清除按钮对齐，搜索结果不再与固定高度标题区域重叠。
- 常用功能前置，下载加速、上传加速和广告关键词排在前面，分类中不重复展示。
- 下载／上传倍率改为可拖动、分档吸附的滑条，支持 `1× / 5× / 10× / 20× / 50×`。拖动仅预览，点击保存才应用，取消不改设置。

### 私聊批量发送

- 入口：**扩展中心 → 自动化 → 私聊批量发送**。
- 输入消息后只读加载当前账号的普通和归档私聊会话，完整分页、去重，并读取完整屏蔽名单；失败或取消时不使用部分名单发送。
- 确认框显示人数和完整消息内容，点击“发送”后才开始；每条间隔至少 3 秒，后台静默提交，不逐条弹窗。有一个静音进度通知，可取消剩余任务。
- 不包含自身、群组、频道、机器人、服务账号、已删除／已屏蔽、需付费或当前账号无 Premium 联系权限的用户。每次提交前再次校验资格；不搜索陌生用户，也无法还原已经删除的历史会话。
- 断网时等待，不推进队列；进程重建后任务暂停，需再次确认才继续，继续前重新读取屏蔽名单。退出登录会清除该账号任务，即使同一用户重新登录也不会恢复旧任务。
- 进度的“已提交”表示已交给 Telegram 发送队列，不代表对方已收到；结果在原会话查看。取消不撤回已提交的消息。Android 系统停止后台任务时保留进度，用户可确认继续。

### 连续播放

- 修复播放结束事件与短视频循环阻碍自动下一条的问题，普通视频加入语音／圆形视频的连续播放队列。
- 全屏查看视频时，可跳过照片衔接已加载列表中的下一条视频；不跨账号或会话、不回绕。
- 已删除、阅后即焚／一次性、隐藏敏感或广告媒体不加入自动队列；明确选择的循环播放优先，关闭自动下一条时不接续。

## 已读乱回范围调整

- 开启“已读乱回”后，默认仅在私信聊天生效。
- 群组需要用户手动选择后才会生效；未选择的群组不会由这项功能标为已读或自动回复，频道不参与。
- 在“扩展中心 → 自动化 → 随机回复群组 → 添加群组”选择需要生效的群组；关闭列表内群组开关即可移除。
- 升级后群组名单默认空，不会把此前开启的总开关视作群组授权。名单按账号和登录用户保存，移除群组后尚未触发的回复也会取消。
- 单独的“自动已读”开关保留原有范围；即使开启该开关，未选择的群组也不会随机回复。
- 新增入口、说明与空列表文案同步覆盖现有 13 种语言。保留前台联网、新消息、每会话 3 秒冷却、去重及不发送付费消息的行为。

## 版本配置

权威版本配置位于根目录 `gradle.properties`。应用和测试模块沿用此处的版本名与基础版本号，客户端显示版本也使用同一配置。

应用产物的 Android `versionCode` 继续按 `APP_VERSION_CODE × 10 + abiVersionCode` 计算；`afat` 为 `70069`，`bundleAfat` 为 `70061`，`bundleAfat_SDK23` 为 `70062`，均高于对应的 4.5 版本。

此前功能及验证记录保留在 [4.5 更新记录](v4.5-release-notes.md)。
