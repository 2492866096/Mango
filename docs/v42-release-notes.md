# Mango IM 4.2

版本从 **4.1 / 7001** 升至 **4.2 / 7002**，统一配置位于 `gradle.properties`。应用、测试应用及 BuildConfig 均引用此配置；ABI 安装版本按原规则 `7002 × 10 + ABI 标识` 生成。包名仍为 `app.mango.im`。

本轮仅修改源码并进行 Java/资源与离线行为验证，不生成或安装 APK。

## 扩展中心

- 上方提供“全部、聊天、隐私、媒体、自动化、外观、工具”分类标签和固定搜索框。
- 搜索覆盖芒果开关、功能子页面与 Telegram 原生设置；搜索结果可直接进入对应设置。
- “最近修改设置”保留最近 200 次记录和修改时间，支持恢复修改前的值；显式设为 0、空字符串与默认继承分别处理。
- “重置操作与扩展设置”需要连续两步确认，恢复行为与外观偏好、停止自动任务，保留账号、聊天、下载文件、代理凭据和任务内容。

## 聊天与消息

- “禁用双击表情回应”保留其他双击动作；已有双击回复设置继续可用。
- 频道人数按服务器返回值显示完整数字，不再缩写为 K/M。
- 管理员头衔跟随昵称颜色；扩展开关控制默认展开引用、始终显示剧透内容、隐藏动态和在本机隐藏自己的动态。
- 收到和发送消息的提示音可分别关闭。
- “自动已读”和“自动已读并随机回复”默认关闭。启用后仅在应用前台、亮屏且联网时处理最近 20 秒的新消息；回复为随机 8 个汉字，同一会话每 3 秒最多回复一次。排除自己发送、已读、服务与付费发送目标；持久化去重避免重连重复回复。已有“隐藏已读状态”仍控制向服务器发送已读回执。
- 关键词通知规则可设为所有消息、仅提及我、仅指定关键词、提及我或关键词。支持全局默认和单独会话覆盖，原有会话静音仍有效，不隐藏聊天内容。

## 发送与媒体

- 手动消息、语音、机器人指令分别支持发送前确认；确认只覆盖当前动作。已启用的每日任务、复读及自动回复继续按既定配置执行。
- 新增默认静音发送；音量减键可保持静音视频的静音状态。
- 附件相册选图菜单增加“图片作为贴纸发送”，转换为 512 × 512 的 WebP 静态贴纸。
- 大文件达到 100 MiB 时提示大小、估计耗时，并提供原文件或 ZIP 压缩发送。估计按 1 MiB/s 计算；ZIP 不修改原文件，对已压缩的图片或视频不保证变小。

## 反诈

原关键词提醒继续使用用户提供的 `反诈.txt` 直链，按两小时周期更新，命中收到消息中的关键词时在聊天输入框上方显示提示。

新增“诈骗用户直链标记”入口，需要单独填写用户名单 HTTPS 文本直链。格式每行 `用户名/ID`，例如 `didb431/7637374698`；也支持单独用户名或 ID。按消息实际发言者精确匹配，英文用户名忽略大小写，兼容活动别名。群聊或私信显示风险提示、用户名和永久 ID，可打开资料拉黑或举报；每次名单更新后每个用户只提醒一次。下载失败保留缓存，空白名单可清除旧名单。名单按账号和登录用户隔离。

本轮没有提供用户名单直链，因此该入口初始未配置。关键词词库与用户名单是两个独立来源。
